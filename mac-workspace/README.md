# Dokkan Unit Creator — iPhone Duo project folder

- `docs/IPHONE-DUO-DISPLAY.md` — the full-screen fix: displays, cause, iOS config, page rules, tests (read first)
- `build/` — newest verified IPA only (sideload with iloader/Sideloadly, or `run/device-install.command`)
- `source/` — full app source (v2.36, Oct 28 2026): `v2/ui` app screens, `web/` build + tests, `dock/` Android, `ios-objc/` iPhone app + `build-ipa.sh` + `check-duo.sh` (build gate), `HANDOFF.md`
- a copy of the source is also in the private GitHub repo mcantua/claude-chatg (`unit-creator/`)
- simulator builds take the app screens from the newest IPA in build/
- `source/web/test_ios_duo.py` — layout regression test (Chromium, both displays)
- `tools/duo-sim-test.sh` — iPhone Duo simulator build/run/log (real Xcode 27.1 SDK)
- `tools/duo-device-test.sh` — sign + install + check on the real phone
- `signing/` — free-account provisioning helper (never installed on the phone)
- `ios-config/Info.plist` — the shipped iPhone settings (generated by build-ipa.sh)
- `run/*.command` — double-click in Finder: sim-test, sim-shot, device-install, device-check
- `evidence/` — test results (display-log.jsonl, screenshots)

## Rule
Every Dokkan Unit Creator release is 3 builds: Android APK, iPhone IPA, and this iPhone Duo version (build gate + both-display test + install and display check on the iPhone Duo with run/device-install.command). Keep only the newest IPA in build/.
- `docs/SEND-TO-GAME.md` — "Import to Eclipse / Sparking": how each game imports, the Sparking patch format, status
- `research/` — what was read from the Eclipse and Sparking apps (manifests, Info.plists, string lists; read-only notes)
- `tools/axml.py` — reads an Android APK manifest

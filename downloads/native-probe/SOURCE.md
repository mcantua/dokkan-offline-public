# Optional native observer tool dependencies

Official PyPI wheels and exact SHA256 values are recorded in manifest.json.
Keystone Engine 0.9.2 assembles leaf ARM64 probes; Unicorn 2.1.4 runs synthetic
instruction checks. This does not execute the original game or prove iOS loading.

Wheels and extracted runtime remain ignored private cloud dependencies for the
shared Drive tool archive. Wheel distribution metadata includes the applicable
licenses; do not ship these cloud development libraries in the app.

Official upstream COPYING files are retained under ignored licenses/ as well as
the binding license in the pinned wheel. Their hashes are in manifest.json.
The Apple dyld MachOAnalyzer reference snapshot and its exact source receipt are
also ignored; it is a format reference, not execution on the current iOS SDK.

# Pinned mobile SQLite

SQLite3.50.4 public-domain amalgamation from the official upstream HTTPS source. Used for the own-app native engine, not copied from a game or Android private system library.

URL: https://www.sqlite.org/2025/sqlite-amalgamation-3500400.zip
SHA256: 1d3049dd0f830a025a53105fc79fd2ab9431aea99e137809d064d8ee8356b032

Archive/extracted source are ignored; the script verifies archive and extracted source. SQLite JSON and STRICT support are required. Both mobile targets link this same version with thread safety and extension loading disabled; no AI/game/signing keys are present.
